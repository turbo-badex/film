# Checklist — Alberta Made Production Grant (AMPG) July 2026 Intake

Official page: https://www.alberta.ca/alberta-made-production-grant  
Guidelines hub: https://open.alberta.ca/publications/alberta-made-production-grant-program-guidelines

## Intake timing
- [ ] Application window confirmed: **July 2–16, 2026**.
- [ ] Internal draft lock deadline set at least 7 days before close.

## Eligibility readiness
- [ ] Applicant structure confirmed as eligible under current AMPG guidelines.
- [ ] Alberta production cost plan assembled and supportable.
- [ ] Project classification and format match AMPG eligibility definitions.

## Core documents
- [ ] AMPG budget template completed.
- [ ] Residency declaration(s) completed.
- [ ] Project synopsis and production plan finalized.
- [ ] Financing plan and cashflow narrative aligned with schedule.

## Optional Training & Mentorship incentive
- [ ] Decision made: include or skip incentive.
- [ ] If included: Training & Mentorship checklist complete.
- [ ] Mentorship agreements drafted for attached positions.

## Submission system
- [ ] GATE access active.
- [ ] Supporting docs uploaded in accepted formats.
- [ ] Final package internally reviewed against evaluation criteria.

## Post-approval readiness (planning)
- [ ] Reporting workflow owner assigned.
- [ ] Principal photography completion evidence workflow defined.
- [ ] Ledger + final budget reconciliation workflow defined.
