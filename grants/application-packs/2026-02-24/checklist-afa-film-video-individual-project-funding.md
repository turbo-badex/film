# Checklist — AFA Film & Video Individual Project Funding (Deadline: 2026-03-02)

Official page: https://www.affta.ab.ca/funding/find-funding/film-and-video-individual-project-funding

## Eligibility checks
- [ ] Lead applicant is Alberta resident (per AFA definition).
- [ ] Applicant in good standing with AFA (no outstanding reporting).
- [ ] Applicant/co-owners are not incorporated for this program stream.
- [ ] Project retains at least 75% copyright with applicant/co-owners.
- [ ] Project not already funded by / eligible for AMF stream that conflicts with AFA rules.

## Account + submission setup
- [ ] GATE Front Office login active.
- [ ] If first-time applicant: registration requested with adequate lead time.
- [ ] Internal submit target set at least 24h before 11:59 PM MT deadline.

## Narrative package
- [ ] 20-word short project description drafted.
- [ ] Detailed project description (objectives, activities, timeline, outcomes).
- [ ] Clear phase definition (script, pre-production, production, post, or marketing segment).
- [ ] Artistic development impact statement included.

## Financial package
- [ ] Expense budget (CAD) complete.
- [ ] Revenue table complete (non-AFA sources + request amount).
- [ ] Request within max $18,000.
- [ ] Basic subsistence costs capped as allowed.

## Attachments (per AFA page)
- [ ] Artistic resume (max 4 pages) for lead applicant.
- [ ] Resumes for all project co-owners.
- [ ] Script excerpts/storyboards/work samples prepared (Windows-compatible audio/video formats if included).
- [ ] Any project-specific support docs required by project type.

## Final QA
- [ ] Names/roles consistent across form + attachments.
- [ ] Dates consistent across timeline and budget.
- [ ] File names clean and submission-ready.
- [ ] Final review complete; submit before deadline buffer expires.
