# Silent Cradle — Budget Assumptions (Working Draft)

## Purpose
This is a planning scaffold for grant applications. It is not a locked production budget.

## Scope assumptions
- Independent Canadian feature (~90 min)
- Alberta-based principal photography
- Primarily practical locations (school, apartment, select exteriors)
- Modest cast size and contained location strategy

## Cost-shape assumptions
- Above-the-line costs controlled through lean producer/director model
- Crew scaled to low-budget professional standards
- Schedule target: 18–24 shoot days (to be validated)
- Post-production planned for efficient sound/edit pipeline

## Funding assumptions by track
### AFA (near-term)
- Ask sized to support script-to-prep/early production activity block
- Max request ceiling considered: $18,000

### AMPG (July intake)
- Base request modeled at 25% of eligible Alberta production costs (max $125,000)
- Optional mentorship top-up evaluated separately (up to $35,000)

### Other sources (to confirm)
- Private equity / deferreds / in-kind / additional grants as stack components
