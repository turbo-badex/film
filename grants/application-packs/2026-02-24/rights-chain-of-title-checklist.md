# Silent Cradle — Rights & Chain-of-Title Checklist

## Ownership foundation
- [ ] Confirm current screenplay author(s) and ownership percentages.
- [ ] Confirm grant applicant has authority to apply and receive funds.
- [ ] Confirm no conflicting assignment, option, or lien on screenplay rights.

## Agreements to assemble
- [ ] Writer agreement(s) / assignment(s)
- [ ] Producer attachment agreement(s)
- [ ] Collaboration agreement among co-owners
- [ ] IP assignment clauses in contractor agreements (where applicable)

## Copyright and control declarations
- [ ] AFA-specific copyright threshold (75%+) validated if using AFA route.
- [ ] Co-owner list consistent across all applications.
- [ ] Moral rights and credit language drafted for key contributors.

## Supporting evidence
- [ ] Dated script versions archived.
- [ ] File naming/version-control log prepared.
- [ ] Signature-ready PDF package assembled.

## Risk checks
- [ ] No use of third-party protected material without license.
- [ ] Music temp usage plan documented (no unlicensed final use).
- [ ] Cultural references and symbols reviewed for respectful use.
