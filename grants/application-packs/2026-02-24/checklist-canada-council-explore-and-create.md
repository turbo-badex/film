# Checklist — Canada Council Explore and Create (Artistic Creation)

Official page: https://canadacouncil.ca/funding/grants/explore-and-create

## Timing and fit
- [ ] Confirm portal opportunity status as active for applicant profile.
- [ ] Confirm project start date is after planned submission date.
- [ ] Confirm this route does not conflict with other funding terms.

## Applicant preparation
- [ ] Canada Council portal account active.
- [ ] Profile/CV up to date.
- [ ] Accessibility/application-assistance need assessed.

## Narrative package
- [ ] Project description drafted (creative intent + process + outcomes).
- [ ] Workplan and milestones clear.
- [ ] Public presentation/dissemination approach included where relevant.

## Financial package
- [ ] Budget and revenue assumptions prepared.
- [ ] Other confirmed/pending funding sources disclosed consistently.

## Evidence package
- [ ] Artistic work samples selected and formatted.
- [ ] Bio/CV + team roles documented.
- [ ] Rights/control documentation prepared where required.

## Final QA
- [ ] Portal field data matches attached docs.
- [ ] Dates and numbers consistent across all sections.
- [ ] Internal reviewer has done final coherence check.

> Note: program detail pages are portal-based and may show additional stream-specific requirements after login; verify before final submission.
