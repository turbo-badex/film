# Payment Proof Checklist (Per Transaction)

For every payment, save all three before marking complete.

## Required evidence
- [ ] Invoice/receipt file
- [ ] Payment proof (bank/e-transfer/card statement line)
- [ ] Deliverable/output link (what this paid work produced)

## Payment proof examples accepted (typical)
- Bank transfer confirmation screenshot/PDF
- E-transfer confirmation email/PDF
- Card statement line + matching invoice

## Quality check before filing
- [ ] Date on payment proof is after/near invoice date
- [ ] Amount exactly matches invoice total
- [ ] Payee name matches invoice vendor name
- [ ] Category matches approved budget line
- [ ] File saved in correct evidence folder

## Suggested file naming
- Invoice: `INV-<vendor>-<date>-<milestone>.pdf`
- Payment proof: `PAY-<vendor>-<date>-<amount>.pdf`
- Supporting deliverable: `DELIV-<name>-<date>.md|pdf|docx`
