# Submission-Ready Final Report Pack Checklist

Use this as final QA before submitting your grant closeout/report.

## A) Core report forms and narratives
- [ ] Final report form completed in portal (or required format)
- [ ] `07-final-report-narrative-template.md` completed
- [ ] `08-financial-report-template.md` completed
- [ ] Reporting dates match approved grant period

## B) Promised deliverables attached
- [ ] Deliverable 1: Treatment (6–8 pages)
- [ ] Deliverable 2: Character descriptions (~2 pages)
- [ ] Deliverable 3: Story outline/structure (2–3 pages)
- [ ] Deliverable 4: Research documentation (3–4 pages)
- [ ] Deliverable 5: Cultural consultation summary (1–2 pages)
- [ ] Deliverable 6: Development plan (1 page)

## C) Financial proof package
- [ ] Budget vs actuals table complete
- [ ] Receipts and invoices attached
- [ ] Consultant proof attached
- [ ] Payment proofs attached
- [ ] Variances clearly explained

## D) Compliance checks
- [ ] No out-of-scope costs reported as grant-funded
- [ ] No duplicate claims against other grants for same costs
- [ ] Deliverables align with originally promised scope
- [ ] Company/applicant details consistent across all docs

## E) Quality and consistency check
- [ ] File names are clear and versioned
- [ ] Dates and dollar amounts are consistent across narrative and financial reports
- [ ] Page counts meet promised ranges
- [ ] Professional proofreading complete

## F) Archive and audit readiness
- [ ] Final submitted package archived locally
- [ ] Source docs + receipts stored in one folder
- [ ] Follow-up questions owner assigned
