## 4) If you are preparing final report submission
1. `07-final-report-narrative-template.md` (or `filled-07-final-report-narrative.md`)
2. `08-financial-report-template.md` (or `filled-08-financial-report.md`)
3. `submission-ready-final-report-pack-checklist.md`
4. `filled-submission-ready-final-report-pack-checklist.md` (working copy)

---

## 5) Weekly operating rhythm (recommended)
- After every payment:
  - update `09-expense-tracker-template.md`
  - save invoice + payment proof + output evidence
- End of each week:
  - reconcile spend vs budget
  - update filled financial report draft
  - close missing evidence gaps immediately

---

## 6) Fast path for your current status
Since funds are in account and no spend yet:
1. Complete `12-first-spend-setup-checklist.md`
2. Execute first 4 planned spends with existing stubs
3. For each cultural/research spend, complete docs 13 and 14
4. Update tracker + evidence folder same day

This will keep your reporting clean and low-risk.
