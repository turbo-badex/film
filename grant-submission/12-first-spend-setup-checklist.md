# First Spend Setup Checklist (Do This Before Spending)

## A) Folder setup
- [ ] Create `evidence/01-writers-fees/`
- [ ] Create `evidence/02-cultural-consultation/`
- [ ] Create `evidence/03-research-development/`
- [ ] Create `evidence/04-admin-professional/`
- [ ] Create `evidence/05-bank-payment-proofs/`
- [ ] Create `evidence/06-deliverables/`

## B) Controls
- [ ] Decide one primary payment method (traceable)
- [ ] Avoid cash payments
- [ ] Confirm approved budget categories only
- [ ] Open/update expense tracker (`09-expense-tracker-template.md`)

## C) Before approving each expense
- [ ] Is it in approved scope?
- [ ] Do I have a proper invoice?
- [ ] Can I tie it to a promised deliverable?
- [ ] Can I save payment proof immediately?

## D) After each payment
- [ ] Update tracker row
- [ ] Save invoice + payment proof + deliverable evidence
- [ ] Reconcile amount in `filled-08-financial-report.md`
